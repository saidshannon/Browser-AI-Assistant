# Browser AI Assistant
**Positioning:** Full-Stack AI Orchestration & Web Automation

### 🚀 Overview
A production-grade AI assistant built to bridge the gap between web content and actionable insights. This project features a high-performance FastAPI backend orchestrating Gemini 1.5 Pro to analyze web pages and YouTube transcripts in real-time.

### 🛠️ Technical Stack
- **Backend:** Python, FastAPI, Uvicorn
- - **AI Engine:** Google Gemini 1.5 Pro, Prompt Engineering
  - - **Frontend:** JavaScript (Chrome Extension API), HTML5, CSS3
    - - **Security:** Environment-based API Key Management
     
      - ### 🌟 Key Engineering Highlights
      - - **Asynchronous Processing:** Leverages FastAPI's async capabilities to handle concurrent LLM requests without blocking.
        - - **Context-Aware Summarization:** Implemented specialized prompts to extract high-signal information from diverse web structures.
          - - **Extension Architecture:** Designed a lightweight manifest v3 extension that communicates securely with the backend via REST.
